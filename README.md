# 🛒 Blinkit SQL Project

![SQL](https://img.shields.io/badge/SQL-Analysis-blue)
![Data](https://img.shields.io/badge/Data-CSV-green)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

Proyek analisis data Blinkit menggunakan SQL untuk menjawab pertanyaan bisnis seputar pelanggan, pesanan, dan detail pesanan.

## 📌 Ringkasan Proyek

Tiga tabel relasional (**Customers**, **Orders**, **OrderDetails**) dianalisis lewat kumpulan query SQL. Daftar pertanyaan tersedia di file `Questions`, dan dokumentasi proyek ada di `BlinkIt Documentation`.

## 🎯 Tujuan

- Memahami struktur data pelanggan dan transaksi.
- Menjawab pertanyaan bisnis dengan query SQL.
- Melatih agregasi, filtering, dan penggabungan antar tabel (join).

## 🗂️ Dataset

| Tabel | File | Isi |
|-------|------|-----|
| Customers | `Customers.csv` | Data pelanggan |
| Orders | `Orders.csv` | Data pesanan |
| OrderDetails | `OrderDetails.csv` | Rincian item pada tiap pesanan |

## 🛠️ Tools

- **SQL** untuk query dan analisis
- **CSV** sebagai sumber data

## 📁 Struktur Repository

```
Blinkit-SQL-project/
├── Customers.csv
├── Orders.csv
├── OrderDetails.csv
├── Questions               # Daftar pertanyaan bisnis
├── BlinkIt SQL Queries.sql # Query penyelesaian
├── BlinkIt Documentation   # Dokumentasi proyek
└── README.md
```

## 🚀 Cara Menjalankan

1. Clone repository:
   ```bash
   git clone https://github.com/achmadhavid/Blinkit-SQL-project.git
   ```
2. Buat database, lalu import `Customers.csv`, `Orders.csv`, dan `OrderDetails.csv` sebagai tabel.
3. Baca `Questions` untuk melihat pertanyaan yang dijawab.
4. Jalankan `BlinkIt SQL Queries.sql` dan bandingkan hasilnya.
